Cấu hình API

Lưu trên trình duyệt của anh — không gửi lên đâu cả

1
Groq API key (miễn phí 100%, không cần thẻ)
Đăng ký bằng email tại console.groq.com → API Keys → Create key · Free 30 req/phút, 1.000 req/ngày
2
GitHub Personal Access Token (để lưu data)
Tạo tại github.com/settings/tokens → Fine-grained tokens → chọn repo cụ thể → quyền Contents: Read & Write
3
Thông tin repo

Bảo mật

  • Tất cả key được lưu trong localStorage của trình duyệt — chỉ máy này dùng được.
  • Trang này nên được chặn truy cập public — đã có sẵn trong robots.txt.
  • Không bao giờ commit key vào source code.
  • Nếu chia sẻ máy, bấm Xóa key sau khi dùng xong.
